# Three-Authority VibeCoding Templates

按状态机顺序使用：

1. [Implementation Authority Instruction](execution-package.md)
2. [Implementation Report](execution-report.md)
3. [Verification Authority Instruction](test-request.md)
4. [Verification Report](independent-test-report.md)
5. [Decision And Acceptance Record](approval-record.md)

所有候选阶段模板必须填写同一个完整 Candidate-Commit。空字段写 NONE 并说明原因，不得删除字段或用模糊引用代替。

文件名为兼容旧安装协议保留；新任务以模板正文中的 Authority 名称为准。
